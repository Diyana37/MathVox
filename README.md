# MathVox

## Предложение 1

**Проблем**
При самостоятелна подготовка студентите често виждат само крайния отговор на задачата, без да разбират логиката и доказателствата зад нея. Имат нужда от обяснения стъпка по стъпка, които да наподобяват реален урок.

**Потребители**
Студенти във ФМИ, които се подготвят за изпити по математически дисциплини като Линейна алгебра или Дискретни структури, и имат нужда от търпелив виртуален преподавател.

**Демо сценарий (Последователен поток)**
1. Потребителят въвежда задача чрез текст.
2. Асистентът я решава и извежда всяка стъпка.
3. Обяснението се прочита на глас чрез TTS (text-to-speech), за да се симулира истински урок.
4. Асистентът генерира сходна задача/куиз, за да провери разбраното, изчаква решението на студента и връща обратна връзка (оценка).

**Техники от курса**
*   **Извикване на API + управление на контекста (Теми 1-2):** Поддържане на историята за проследяване на стъпките в урока.
*   **Structured Outputs (Тема 3):** За генериране на куизове и строга оценка на отговорите в JSON формат.
*   **Мултимодалност (Тема 13):** Аудио (TTS) за гласовите обяснения
*   **Guardrails (Тема 14):** Ограничаване на модела само до математическия домейн.
